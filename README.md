# 코트사이드 · 한전 본사 테니스

송변전·배전 각 4명의 친선 복식 대항전을 위한 첫 버전입니다.

## 지원 기능
- 일정, 시작 시간, 1~6번 코트, 사내 예약 승인 상태 안내
- 복식 3경기 또는 5경기, 팀별 4명과 경기별 선수 2명 입력
- 팀 대표 전용 링크로 자기 팀 오더 제출 및 수정
- 양 팀 제출 후 진행자 확정, 확정 전 상대 오더 비공개
- 진행자만 최종 게임 스코어 입력·수정·초기화, 팀 승수 및 승리 팀 자동 계산
- 서버 저장, 다른 기기에서 조회, 30초 간격 갱신, 동시 수정 충돌 감지
- 결과 CSV 다운로드, 모바일 화면

## 실행
Node.js 22.13 이상과 npm이 필요합니다.

```sh
npm install
npm test
npm run typecheck
npm run build
npm run dev
```

Cloudflare D1의 DB 바인딩과 환경 변수 ADMIN_KEY가 필요합니다. INITIAL_ROSTER는 선택 항목이며 a, b 각각 4개 이름을 갖는 JSON 문자열입니다. 실제 참가자 정보와 관리 키는 소스에 포함하지 않습니다. 개발용 변수는 Git에서 제외되는 .dev.vars에 설정합니다.

로컬 D1에는 최초 한 번 drizzle/0000_young_talos.sql을 적용합니다. npm run build 이후 다음 명령을 실행합니다.

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_young_talos.sql
```

## 운영과 권한
일반 URL은 열람용입니다. 진행자 링크는 /#key=ADMIN_KEY 형식입니다. 진행자 화면에서 팀 대표 링크를 복사할 수 있습니다. 대표 키는 서버에서 HMAC으로 파생되며 상대 팀 변경이나 결과 입력을 허용하지 않습니다. 링크 소지자는 해당 권한을 가지므로 각 담당자에게만 전달합니다. ADMIN_KEY를 교체하고 재배포하면 이전 관리 링크가 모두 무효화됩니다. 참가자 이름·일정·확정 오더·결과는 공개 링크에서 열람할 수 있습니다.

데이터는 단일 대회 레코드로 저장합니다. 날짜를 바꿔도 별도 대회가 생기지 않습니다. 여러 대회 이력, 개인 랭킹, 사내 예약 시스템 연동, 자동 메시지 발송은 이번 버전에 포함되지 않습니다. 관리 키를 분실하면 운영 환경 변수에서 새 키를 설정하고 재배포합니다.

3경기에서는 2승, 5경기에서는 3승으로 대항전 승리 팀을 판정합니다. 스코어는 한 경기의 최종 게임 수이며 0~99의 정수, 동점 불가입니다. 세트별 상세 기록·기권 처리는 지원하지 않습니다. 노애드·타이브레이크 등 세부 규칙은 진행자가 안내문에 작성합니다. 우승이 결정돼도 나머지 친선 경기 결과를 기록할 수 있습니다.

## 검증
npm test는 역할별 권한, 중복 선수, 오더 확정, 스코어 수정 및 초기화, 경기 수 변경, 승리 팀 판정을 검증합니다. GitHub Actions는 테스트, 타입 검사, 빌드를 실행합니다.

초기 PR은 잠금 파일을 포함하지 않으므로 첫 실행에 npm install을 사용하세요. 전달된 소스 ZIP에는 검증에 사용한 package-lock.json이 포함되어 있습니다.
